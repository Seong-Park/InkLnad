## 맵

K1의 파라다이스 → 고스트블루 → 메갈로폴리스 진행 축을 유지한다. 이 화살표는 지역 진행이며 직접 포털 연결이 확인됐다는 뜻이 아니다.
각 지역은 안전 마을, 여러 필드, 게이트, 별도 던전으로 분리한다. 원작 이름은 데이터의 참고 ID로 사용하고 화면상의 이름과 그림은 Ink Land 세계관으로 제작한다.
B2의 지역 항목을 확장 목록으로 기록하고 첫 구현은 파라다이스 대응 거점과 주변 필드, 던전 갈림길로 제한한다. 전체 원작 맵 재현은 이 첫 구현의 완료 범위와 별도로 남긴다.

원작 세부 포털 근거가 없으므로 첫 테스트 연결은 P다:
`village <-> meadow_gate <-> meadow_1 <-> meadow_2`.
`meadow_1 <-> meadow_3`, `meadow_2 <-> dungeon_gate <-> dungeon_1`.
이는 원작 인접성을 복원한 지도라고 표시하지 않는다. 이후 자료가 확보되면 연결 데이터만 교체한다.
필드를 전부 처치해야 출구가 열리는 기존 A~F 방식은 사용하지 않는다. 필드 이동·사냥·발굴·거점 복귀를 자유롭게 반복한다.
몬스터는 필드별 개체로 재등장한다(P: 처치 후 30초). 발굴 보상도 재시도 가능한 자원이며 퀘스트/복원 최초 보상만 한 번 지급한다.
영구 지점 상태와 재생 자원 상태를 구분해 저장한다.

## 캐릭터 성장

K: 일반 레벨과 통합 TM 레벨은 별도 진행으로 취급한다.

B1: 레벨업 보너스 4포인트를 능력치 성장에 배분하며 4틱 단위를 누적한다. 표시값과 성장 틱을 별도로 저장해 소수 누적을 잃지 않는다.
12능력치는 물리공격/명중/공격속도, MP/마법방어/마법공격, 무게/감지/행운, HP/방어/회피를 각각 분리한다. 개별 한국판 기본값은 미확인이다.
경험치 표는 P로 명시한다: 레벨 L의 다음 일반 경험치 `100 * L * L`, TM 경험치 `80 * L * L`.
획득량도 P다: 첫 필드 몬스터 일반 20/TM 10, 발굴 성공 일반 10/TM 5. 두 경험치 모두 해당 테이블로 반복 레벨업 계산한다.
수치표에는 source_status/source_url을 붙인다. 임시 표를 원작 경험치 곡선으로 표시하지 않는다.

## 전투와 스킬

마법은 대상·사거리·MP·선행 조건을 확인한 뒤 시전 → 해결 → 재사용으로 진행한다. HP와 MP는 분리한다.
B1로 카드와 TM 포인트 학습, 스킬 강화, 마스터 조건을 구분한다.
첫 공격 버튼은 배우고 장착한 단일 대상 마법을 사용한다. 무료 즉발 마법탄을 별도 평타로 만들어 원작 마법 성장과 분리하지 않는다.
B1의 초기 공격 마법 1레벨을 보완 기준으로 사용한다: TM 1, 카드 가격 300, 학습 1포인트, MP 50, 시전 1.5초, 공격 계수 230. 피해 전 마법방어 계산의 기준식은 `(MA - 49) * 230 / 10`이다.
P: 해당 1레벨 재사용은 1초, 사거리는 월드 320, 마법방어 적용은 `max(1, floor(raw - MD))`. 명중은 첫 버전에서 `clamp(0.85 + (player_luck-enemy_luck)*0.005,0.1,0.98)`로 설정한다. 모두 원작 공식이 아니라 임시값이다.
P 시작 능력치는 테스트 가능한 MA 53/MP 170/HP 150으로 두고 원본값 확보 시 교체한다.
B1: 적 공격에 의한 시전 방해와 이를 막는 패시브를 분리한다. 이동 시 취소 여부는 자료 불충분하므로 P로 이동 시 취소한다.
해결 전에 대상 사망·맵 이동·일시정지가 발생하면 유효하지 않은 대상을 공격하지 않는다. P: MP는 해결 시 한 번만 소비하며 취소 시 소비하지 않는다.
마나 회복/포션이 필요한 전투를 유지한다(P: 비시전 상태 초당 8MP). 대시·무료 범위기는 첫 기본 구성에서 제외한다.
전직은 K2의 레벨60/TM50/퀘스트를 참고한 후속 범위다. 후기 전직 수치와 혼합하지 않는다.

## 발굴과 복원

B3의 검색 발췌는 도구별 최대 깊이·수명·요구 레벨·무게가 다른 것을 보여준다. 개별 수치는 한국 초기판 보장이 없다.
붓은 최대 깊이·내구도·적합 지형을 가진 발굴 장비로 표현한다. 땅을 칠하는 연출 뒤 발견물이 드러난다.
P: 첫 붓 최대 깊이 40/내구도 200/요구 레벨1. 초원 깊이는 10~30, 초기 던전 30~60. 탐색마다 실제 깊이와 도구를 비교한다.
P 미니게임은 누름/해제로 게이지를 유지한다. 0~1 게이지의 0.35~0.75 영역에 누적 1.5초 유지하면 성공하고, 범위 밖 누적 0.5초면 실패한다. 이동·피격은 취소한다.
P: 성공·실패는 내구도1 소비, 취소는 소비하지 않는다. 성공 시 깊이/지역 드롭 풀에서 한 번 추첨하고 초과 무게면 획득을 막는다.
인벤토리·무게·장비 성장은 유지하되 안료와 복원은 Ink Land 독자적 규칙이다.
첫 복원은 P: 안료10을 소비한다. 소비와 복원 플래그를 함께 저장한 뒤 색 번짐 연출을 시작한다. 저장 실패 시 지급/소비 성공을 표시하지 않는다.
