# 수채화 해안 맵 재설계 시안

2026-10-03. 사용자 피드백에 따라 제작한 Ludo 콘셉트. 게임에 적용하지 않은 설계 이미지이며, 원작 지도 좌표를 복원한 자료가 아니다.

## 마을

`village-concept.webp`: 분수를 중심으로 세 서비스 건물의 입구를 광장 쪽으로 모은다. 파란 지붕은 붓 공방, 산호색은 안료 상점, 초록색은 지도 제작소다. 남서쪽 정원은 튜토리얼 공간, 남쪽 부두는 이야기 지점으로 사용한다. 지면은 낮은 대비로 유지하고 수풀·낮은 바위·해안으로 공간의 경계를 만든다.

마을은 여러 필드로 나가는 거점으로 설계한다. 북서·북·동쪽 길은 향후 개별 필드 출구 후보이며 원작 출구의 실측 위치가 아니다. 첫 구현에서 해안 필드 연결만 활성화해도 나머지 연결 계획을 남긴다. 건물과 부두의 크기는 실제 플레이어 및 카메라 화면에 맞춰 다시 정한다.

## 필드

`field-concept.webp`: 서쪽 입구 → 분기 → 북쪽 사냥 공터 / 남쪽 발굴 해변 → 동쪽 합류 구역. 중앙 호수와 바다를 잇는 수로에 다리를 둔다. 북쪽 폐허는 위치를 기억하는 표식이다. 돌아오는 길을 선택할 수 있는 순환 동선으로 만든다.

생성 이미지 왼쪽 위의 주택들은 필드 제작에서 제거한다. 높은 바위는 낮은 바위와 수풀로 단순화하고, 이동 영역·충돌·전투 공간은 별도로 작성한다. 이미지에 등장한 조개는 발굴 기능 구현을 뜻하지 않는다.

## 실제 적용 — 2026-10-04

위 문단은 최초 콘셉트 단계 기록이다. 현재 A/B 맵은 한 장의 콘셉트 그림을 배경으로 붙이지 않고, 64픽셀 TileMapLayer와 개별 소품으로 구현했다. 바닥은 모래·풀·물·흙·돌바닥의 다섯 재질에 연속적인 혼합을 적용한다. 마른 모래에서 젖은 모래, 얕은 물에서 깊은 물로 이어지며, 풀밭 가장자리는 희박한 풀과 모래가 섞인다. 잔풀·조개·자갈은 별도 소품이다. 한옥풍 건물과 소나무·버드나무·대나무를 사용한다.

초기 트릭스터 해변 화면에서 낮은 대비의 모래 흔적, 얕은 물, 가장자리 소품, 열린 이동 공간을 참고했다. [TricksterMap 도구](https://github.com/Raymonf/TricksterMap)는 원작의 타일·오브젝트·충돌 데이터 구분을 확인하는 참고다. 우리 호수와 연결 좌표는 원작의 정확한 복원이 아니다.

A는 공방·연습 정원·광장·부두와 B로 가는 출구를 제공한다. B는 호수 북쪽 길과 남쪽 해변 길이 다리 부근에서 합류하는 동선을 제공한다. 발굴 표식은 현재 장식이며, 안료 상점·지도 제작소도 외형이다. 모바일 조작 및 전체 TM/캐릭터 시스템은 이번 지형 변경의 검증 범위에 포함되지 않는다.

검증: `docs/verification/coast-modular-v3/manifest.json`, 실제 화면 `captures/`. 해안 충돌·다리 횡단·부두 끝 이동·왕복 출구·공방 상호작용을 검사했고, 기존 여정 회귀 검사 일곱 항목도 통과했다. 지형 셰이더는 Area의 (80,80) 오프셋을 빼서 지역 좌표로 마스크를 읽는다.

### 타일 시안에서 실제 맵으로

같은 날짜의 후속 작업에서 `coast-tiles-v4`의 새 바닥 재질과 해안 절벽 그림을 A/B 런타임에 적용했다. 절벽은 원래 곡선 해안의 지형 좌표를 따라 이어지고, 정원 풀밭과 울타리·밟힌 길을 추가했다. 별도 타일 조합 샘플이 아닌 실제 여정 맵의 화면은 `docs/verification/coast-world-v5/captures/`에 있다. 이전 단계 기록과 구분해 이 경로를 최신 적용 결과로 본다.
