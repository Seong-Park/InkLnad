# 직접 그리기·잉크 효과 계획 v0.1

FE-EFFECT-001 / effect-designer / 2026-10-03 / Godot 4.7.2. 상태 submitted: fe-manager 검토 요청. 이번 산출물은 문서만이며 코드·씬·이미지·실행 테스트를 만들지 않았다. 아래 경로·ID·크기·시간·렌더링/접근성 정책은 모두 미확정 제안이며 구현 승인이 아니다.

읽은 기준: AGENTS.md, game-direction v0.2, workflow, contracts v0.1, effect-designer/fe-manager/fe-plan v0.1, FE map-plan v0.1, GDD v0.1 HTML과 메뉴 PNG. godot-animation/animation-tree-and-tween 및 godot-nodes-scenes/tree-and-instancing을 적용한다. 최신 기획의 직접 화면 그리기·기사 주변 제한·일시 잔흔이 기존 방향 조준/부채꼴 공격을 대체한다. 붓의 넓고 약한 공격과 연필의 좁고 강한 공격은 확정 방향이나 실제 굵기·피해·수명은 BE/master 결정이다.

## 승인 데이터와 시각 경계

FE 입력→BE 좌표 변환/반경 절단/잉크 검사→승인 선분→effect 표현의 순서다. 선의 시작점은 승인된 화면 드래그 지점이며 기사나 화구 끝에서 강제로 연결하지 않는다. 기사 반경의 값·링·커서는 effect가 만들지 않는다. 효과는 승인된 월드 선분의 끝점과 실제 굵기를 그대로 사용하며 카메라 이동이나 기사 이동에 맞춰 기존 선을 끌고 가지 않는 후보를 제안한다. 생성 후 반경 이탈 시 잔흔 유지/종료는 BE 정책을 따른다.

| 공동 계약 입력 | 소비/추가 인계 제안 |
|---|---|
| stroke_id, tool_id, owner | 공격 인스턴스 식별·도구 재료감 선택·소유자 구분. 노드 저장용 owner와 게임 소유자 ID는 별개 |
| 승인 월드 선분 목록, 실제 굵기 | 분리 선분 각각 표현. 바깥 두 점·이탈 재진입·부족 잉크 구간을 임의 보간하지 않음 |
| 생성 시각, 유효 수명 | BE의 시간 기준을 소비. 일시정지/종료/취소를 포함한 유효 상태는 BE가 제공하며 애니메이션 완료로 피해를 종료하지 않음 |
| 추가 계약 후보: revision/선분별 생성시각·종료시각, area_id, active/expired/cancelled, 상태 시각 | 긴 드래그의 먼저 그린 부분과 최신 부분을 구별하기 위해 BE에 요청. 중복·역순 갱신/전환 뒤 오래된 이벤트를 구분할 방안은 BE/master 승인 필요 |

팔레트는 GDD 기본 5색을 준수한다: 종이 #F3E5C9, 선화 #3B3430, 코발트 #1749C6, 따뜻한 빛 #D99835, 위험 #8D3154. 붓은 코발트 불규칙 내부 결에 선명한 실제 경계, 연필은 얇은 코발트 중심선과 선화 긁힘 결 후보다. 실제 굵기를 텍스처 크기에 맞춰 바꾸지 않는다. 경계 밖 물감 번짐은 낮은 농도의 끊긴 얼룩으로 구분하며 피해가 없는 장식이다. 시작 후보는 실제 경계 밖 번짐 최대 4월드 단위/불투명도 0.15이나, 좁은 연필과 작은 화면에서 범위 오인 시 번짐을 생략한다. 월드 단위는 map의 1단위=1px 후보와 함께 승인받는다.

유효 잔흔은 승인 경계를 끊김 없는 윤곽+내부 결로 표시한다. BE가 expired를 알린 순간 유효 윤곽을 제거하고 흐릿한 점 얼룩으로 전환한다. 무해 잔흔 소멸 시간 0.25초/최대 불투명도 0.10은 후보이며 유효 수명을 연장하지 않는다. 공격 끝점 장식도 승인 선분의 연속성을 바꾸지 않는다. 적/기사 윤곽과 위험 해칭이 우선이며 장식이 가리면 장식 농도·수를 줄인다. 겹침 수가 많아도 유효 선분을 합쳐 새 피해 면처럼 보이게 만들지 않는다.

## 상태 효과와 첫 10분 적용

고갈은 BE 승인 종료점에서 젖은 물감 생성을 멈추고 짧은 마른 결 소멸(0.15초 후보)을 보여준다. 충전 시 캐릭터의 도구 앵커에 작은 코발트 점이 차오르는 장식(0.4초 반복 후보)을 제안한다. 병/게이지/HUD는 FE 소유다. 충전율·충전 시작 지연·고갈 유지 입력의 자동 재공격은 계산하지 않으며 BE 상태가 바뀔 때만 표현한다. 회수 잉크 획득을 전투 잉크 충전으로 보이게 하지 않는다.

피격은 BE의 확정 hit 위치에 선화/위험색 파편을 짧게 표시(0.12초 후보)한다. 파편은 충돌/넉백/무적을 만들지 않는다. character의 몸 윤곽 강조와 effect의 바깥 파편이 겹치지 않도록 하나의 hit ID/시간/대상 앵커 인계를 요청한다. 복원 성공 때 따뜻한 빛의 점이 map 제공 앵커로 스며드는 일회 장식(0.6초 후보)만 맡는다. 꽃집 채색·영구 상태·환경 idle은 map, 승인/저장은 경제 담당이다. 실패/이미완료/재로드에 성공 장식을 재생하지 않는 후보이며 보상 요청은 하지 않는다. reduced-motion 후보는 잔흔 상태 전환을 유지하되 반복 점·파편 이동·복원 점 이동을 생략한다.

첫 10분은 map의 시간 후보를 따른다: 공방 0:00–1:30에서 선→유효 잔흔→무해 소멸과 공격 중지 후 충전을 경험; 연결 길 1:30–2:30에서 이동 카메라 아래 월드 고정 선과 경계 이탈을 확인; 공터 2:30–4:30에서 곡선 잔흔으로 적을 유도; 갈림길 4:30–5:30은 장식을 쉬어 표지/회수 재화를 읽게 한다. 정예 뜰 5:30–7:30은 붓/연필 비교 후보(지급·장착은 미확정), 꽃집 7:30–8:30은 승인 복원 점과 map 채색을 구분, 귀환/구매 8:30–10:00은 전투 효과를 정리하고 FE 정산 표시를 소비한다. 시간은 강제 타이머가 아니다.

고정 파편은 AnimationPlayer, 상태별 짧은 장식 투명도 변화는 node-bound Tween 후보다. 같은 속성을 두 도구가 동시에 쓰지 않는다. animation_finished는 장식 노드 정리만 허용하며 게임 판정을 호출하지 않는다. BE 취소/구역 해제 시 Tween 취소와 안전한 노드 해제를 요청한다. 새 autoload·셰이더 의존성·풀링은 선행 도입하지 않는다. 실제 래스터 제작 승인 시 imagegen 스킬과 도구를 사용한다.

effect 독점 제안 범위는 scenes/effects/, scripts/effects/, assets/effects/, resources/effects/다. FE 매니저에 메뉴/Control/HUD/링/커서와 reduced-motion 설정 전달, map에 저대비 바닥·복원 앵커·채색 동기화, character에 화구/발/피격 앵커와 몸 모션 분리, gameplay에 승인 선분·단일 시간 기준·부분 승인·중복/취소/구역 수명, 경제에 복원 승인 결과를 요청한다. 공용 스키마/ID 등록은 master가 결정하며 effect가 BE 부모 씬이나 공통 계약을 수정하지 않는다.

## 미래 검증과 실제 검토

구현 승인 후 AGENTS.md의 bridge 프로젝트/열린 씬/스크립트 버퍼 확인→저장/동기화→headless import→변경 씬/테스트→stdout·stderr·명시 종료 코드·기대 마커 기록을 따른다. timeout은 통과가 아니다. QA/BE의 승인 데이터 로그와 FE 영상/판정 경계 캡처를 함께 비교한다.

- UI 시작 드래그/멀티터치, 반경 바깥 두 점·이탈 재진입·빠른 입력/제로 길이: BE가 거절한 선/연결/장식 공격이 생기지 않음. 같은 점 유지의 피해/잉크 규칙은 BE 검증.
- 카메라 추적·줌/창 크기·30/60/144fps·기사 이동: 승인 선분 끝점/굵기/월드 고정 일치, 적 윤곽과 해칭 노출. 장식 번짐을 피해로 오인하는지 관찰.
- 부분 잉크 승인/고갈 유지/충전/도구 교체/중첩: 마지막 승인점에서 종료, 거절 구간 없음, active→expired 시 윤곽 제거; 자동 재공격 정책은 BE 결과만 표시.
- 일시정지/포커스 상실/구역 이동/역순·중복 이벤트/없는 tool_id: BE 시간·취소 일치, 오래된 선 재생성 없음. 누락 ID는 임의 유효 선 대신 표시 보류/오류 인계 후보.
- 꽃집 성공/실패/이미완료/연출중종료/재로드: 승인 성공 때만 일회 장식, map 최종 상태 일치, 회수 잉크와 충전 표현 혼동/중복 보상 없음. reduced-motion에서도 실제 경계/수명 상태 식별.

실제 검토는 문서의 최신 직접 그리기·계약 필드·5색·타 역할 경계·수치 제안 표기와 git status 대조다. 출발 시 project.godot 수정, docs/agents/·docs/design/·godot/addons/godot_ai/ 미추적 상태를 확인했고 보존했다. effect-plan.md만 작성했다. headless/구현 테스트는 실행하지 않았다. self-learning을 적용해 승격 조건을 검토했으나 통과 체크+이름 있는 실패+시도한 막힌 길이 없어 lesson을 추가하지 않는다. FE/BE 매니저 합의 후 master에 좌표 척도·시각 정책·상태 인계 확정을 요청하며, fe-manager의 accepted/revision-required 검토를 요청한다.
