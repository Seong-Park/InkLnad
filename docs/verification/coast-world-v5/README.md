# 실제 해안 맵 적용

2026-10-04, Godot 4.7.2. A/B 메인 여정 맵에 새 watercolor 타일 그림을 적용했다. 별도 WatercolorTileStudy만 바꾼 결과가 아니다.

- 바닥: coast-tiles-v4의 모래·풀·물·돌바닥 재질을 지역 지형 마스크와 혼합한다. 소스 셀 가장자리 4px를 제외하고 미러 반복해 잔여 경계선을 줄인다.
- 해안: 기존 물 폴리곤을 따라 해안 타일의 절벽·포말을 MeshInstance2D로 이어 붙인다. 카메라에서 육지가 물보다 위에 있는 구간에만 남향 절벽을 보인다. 이동 충돌은 기존 물 폴리곤과 다리·부두 개구부를 유지한다.
- 마을: 공방·분수 광장·연습 정원·부두를 연결한다. 연습 정원 풀밭과 장식 울타리를 추가했다. 울타리는 장식이며 충돌체가 아니다.
- 필드: 호수 북쪽과 남쪽 두 길이 다리 부근에서 합류한다. 경로의 풀을 줄여 밟힌 길을 구분한다. 동양풍 건물과 소나무·버드나무·대나무는 독립 오브젝트로 유지한다.

`manifest.json` 및 stdout/stderr는 해안 이동 검사와 실제 GPU 렌더링 결과다. 캡처는 `captures/`에 저장했고 마을 전체·정원·다리·필드 전체를 직접 열어 확인했다. 기존 여정 회귀 결과는 `../first-journey/manifest.json`이다.

검증 중 발견한 울타리 배열-벡터 뺄셈 문법 오류는 점별 오프셋 배열로 수정했다. 최종 실행에서는 exit 0, 기대 PASS marker, 빈 stderr를 요구했다. 이미지 출력 marker만으로 통과 처리하지 않는다.

지형과 좌표는 Ink-Land의 원본 설계이며 트릭스터 원본 지도 복원은 아니다. A/B 외의 지역, 모바일 조작 및 TM 시스템은 이번 변경에 포함되지 않는다.
