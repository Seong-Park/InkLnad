# Rejected v22 idle experiment

These are unmodified LUDO outputs, **not runtime art**. See `../REPORT.md` for why they were rejected. `provenance.json` contains source job IDs, prompts and generation results. Full GIFs contain camera-turning frames and must not be presented as previews of the implemented idle motion.

Initial images were exported directly from v21 native walk frame 0. The animation prompt was: “Standing idle with both feet planted, breathing gently, blinking, ears and tail swaying. Keep the exact source viewing angle and character proportions. Fixed camera. No walking.”

The intermediate `frames.json` records attempted stable-angle selections. Matching head size did not preserve silhouette/face direction, so the runtime uses the original walk atlas instead. Generation artifacts remain here for provenance; they are outside the game asset directory.
