## 1. 확정 사항과 승인 요청의 경계

사용자 확정은 수채화 시각, 종이 기사, 독립 이동·직접 그리기, 기사 주변 제한, 일시 공격 잔흔, 제자리 유지 공격, 길이+유지 비용, 덧칠 재소비·부분 수명 갱신·무한 중첩 금지, 고갈 시 이동·기존 잔흔 유지, 입력 해제 후 0.5초 충전 대기와 새 press 재공격, 전투/구매 잉크 분리, 연결 구역 탐험·마을 구매·세계 복원, 레벨업 3택 제외다.

아래 상세 수치와 규칙은 **master 승인용 프로토타입 초기값**이다. 최종 플랫폼·시점·난이도·콘텐츠 확정으로 확대하지 않는다. 이전 보고서의 총 4초 회복 목표를 이어받는다. 기존 game-direction v0.4의 미확정 부분을 구체화하되 이번 파일 제출만으로 기준 문서를 변경하지 않는다.

공통 월드 좌표는 방별 좌상단(0,0) 기준이다. 고정방은 1120×560의 플레이 영역을 화면 중앙에 배치하고 나머지 공간을 종이 여백/HUD로 쓴다. 기사와 적 좌표는 아래 표의 방 로컬 좌표다. 추적 연결 길은 1680×560이다. 지형은 외곽 벽과 명시된 장애물만 둔다.

### 포인터·경계 규칙

- 왼쪽 버튼 press가 UI·여백에서 시작하면 해당 hold 전체를 공격에서 제외한다. 이동 키는 공격과 독립이다. 오른쪽 버튼은 사용하지 않는다.
- 유효 press는 현재 표시 카메라와 기사 위치를 한 시점으로 참조해 world 점으로 변환한다. 마우스 실제 이동 이벤트만 새 경로를 만든다. 카메라만 움직여도 새 선이나 길이 비용이 생기지 않는다.
- 정지 포인터는 마지막 유효 world 점에서 유지 공격한다. 기사 이동으로 그 점이 반경 밖이 되면 새 피해·갱신·비용은 중단한다. 누른 상태이므로 충전은 시작하지 않는다. UI는 “공격 범위 밖 · 손을 떼면 충전”을 표시한다.
- 실제 입력 위치에는 작은 연필촉 커서를, 유효 유지 world 점에는 속이 빈 공격 원을 별도로 표시한다. 추적 카메라가 움직이면 공격 원만 world 점을 따라 화면 위치가 바뀌며, 실제 커서는 물리 마우스 위치에 남는다. 다음 물리 마우스 이동 때 현재 화면 변환으로 새 world 점에 재anchor한다. 이전 고정 world 점과 새 점이 모두 현재 기사 full-width 범위 안일 때만 연결한다. 둘 중 하나가 밖이면 앞선 경계 이탈·재진입 규칙으로 유효 부분만 승인하거나 새 점부터 시작하고, 바깥 경로를 가로지르는 선을 만들지 않는다. 연결 가능 시 발생한 실제 world 거리에는 길이 비용을 부과한다.
- 범위 밖에서 시작한 press는 같은 hold에서 안으로 이동하면 그 재진입 점부터 시작할 수 있다. 반경 밖→밖 선으로 내부를 가로지르는 공격은 만들지 않는다. 내부→밖 선은 유효 부분까지만, 밖→내부는 재진입점부터만 그린다. 중단된 선과 새 선은 연결하지 않는다.
- full-width 제한: 도구 반굵기 r을 뺀 반경 `180-r` 안에 중심 경로를 clip한다. 끝점은 반원 캡이며 실제 굵기 전체가180 안이다. 기사 중심 이동 시 현재 경로를 매 처리 시점의 중심으로 재검사한다. 밖에서 대기하다 기사 이동으로 마지막 world 점이 다시 허용되면 그 점 유지 공격을 재개하되 건너뛴 선을 잇지 않는다.
- 메뉴·포커스 상실·방 전환·피해로 사망은 강제 release+새 press 요구. 일시정지 중 잉크·피해·적·잔흔 시간은 모두 정지한다. 복귀 시 hold를 복원하지 않는다.

### 비용·부분 선·피해 판정

- 기준 시뮬레이션60Hz를 가정하되 비용·수명은 실제 게임 경과시간에 비례한다. 유효 hold의 유지 비용은 `유지율×dt`, 새 유효 경로 비용은 `길이율×거리`다. UI·경계 밖 구간은 소비하지 않는다. 유효 길이는 덧칠도 다시 계산하며 굵기는 도구별 계수에 이미 반영한다.
- 최소 시작/재개 잉크1.0을 요구한다. 시작 수수료는 없다. 1 미만 press는 “잉크 부족 · 손을 떼어 충전”을 표시하고 공격을 시작하지 않는다. hold 중 충전·자동 시작은 없다. release 뒤 지연·충전을 거쳐 새 press한다.
- 잉크가 한 처리 구간 비용보다 적으면 유효 경로/시간을 동일 비율로 앞부분만 승인한다. `비율=잔여/(유지비+길이비)`이며 승인된 길이와 유지 시간을 이 비율로 줄이고 잉크0이 된다. 길이0인 유지도 시간을 비율로 줄인다. 승인된 부분의 잔흔만 생성한다. 좌표와 피해는 승인 시간·부분 경로만 사용한다.
- 직접 피해는 이번 처리에서 승인된 선/유지 점에 접촉한 적에게 적용한다. 오래된 선은 hold 유지 중에도 잔흔으로 분류한다. 적마다 모든 도구를 공유하는 피해 가능 시각이 있고 첫 접촉은 즉시, 다음은0.25초 뒤다. 한 가능 시각에 직접 접촉이 있으면 직접 피해 하나, 없으면 겹친 잔흔 중 피해가 가장 큰 하나만 적용한다. 연필 교체·빠른 흔들기·stroke ID 변경으로 이 간격을 초기화하지 않는다.
- 덧칠은 닿은 로컬 부분의 마지막 유효 시각만 갱신한다. 전체 선 수명 갱신·피해 누적·넓이 증가 없음. 기사 이동·release 후에도 월드에 고정된다. 잔흔은 몬스터에게만 피해, 기사·주민·지형에는 피해 없음.
- 잔흔의 최소 표현은 **고정 월드 간격4단위의 원형 stamp 합집합**이다. 최초 승인점과 승인 경로의4단위 간격점에 반굵기16/6의 원을 놓고, 마지막 끝점도 놓는다. 마우스 이벤트 사이에는 거리 나머지를 이어서 유지하므로 이벤트 빈도가 샘플 밀도를 늘리지 않는다. 모든 stamp 중심을 full-width 유효반경 안에 제한한다. stamp마다 tool_id·중심·마지막 유효 시각이 있다. 같은 도구의 기존 stamp 중심과 새 샘플 거리가2 이하이면 가장 가까운 하나의 시각만 갱신하고 새 stamp는 추가하지 않는다. 동률은 먼저 생성한 것을 선택한다. 거리가2 초과면 새 stamp 생성. 정지 유지는 같은 stamp 하나만 갱신한다. 여러 원이 겹쳐도 피해는 위 공통 간격·최대 하나 정책을 따른다. 직접 접촉도 이번 승인 stamp 합집합만 사용한다. 샘플 끝점의 겹침은 미세한 모양 차이를 허용하되 비용은 실제 승인 길이로만 계산한다. 격자·분산 revision·이벤트버스는 요구하지 않는다.
- 1키 붓/2키 연필, 구매한 도구만 선택. hold 중 교체 시 입력 취소, 기존 잔흔 유지,0.5초 충전 대기 시작, 새 press 요구. 공유 피해 간격은 유지한다. 도구 교체 시간 비용·애니메이션 잠금은 없다.
- 고갈 시 새 공격 중단, 기존 잔흔·이동 유지. 누른 채 잉크0 유지. 실제 release 이후0.5초를 센다. 전투 잉크와 회수 잉크 HUD·데이터를 별도로 유지한다.

## 4. 기사·적·정예

기사 HP100, 접촉 피해 후0.75초 무적. 피해는 숫자·윤곽 점멸로 표시하고 화면 섬광·넉백 없음. 다음 표에서 좌표는 적 중심, 충돌/피해 판정은 원이다. 적은 기사만 추적하며 잔흔을 회피하지 않는다. 적 간 단순 분리만 적용하고 증원·무한 생성·분열은 없다.

모든 적의 몸 접촉과 투사체는 기사 공통 무적을 존중한다. 같은 시각 다중 피해는 한 번만, 피해가 가장 큰 사건 우선. 예고는 색과 방향 선·확대 윤곽으로 표현한다. 죽은 적은 즉시 판정에서 제거하고 처치 보상은1회만 지급한다. 전투 잉크 드롭은 없다.

기사·적 원형 몸은 방 외곽과 D 장애물에 충돌한다. 투사체는 반경5 원의 연속 이동 경로가 벽·장애물에 닿는 첫 지점에서 소멸한다. 적 돌진도 이동 경로 충돌을 검사하고 벽·장애물 첫 접촉에서 정지해 회복 단계로 전환한다. 접근형과 돌진형의 평상시 이동은 방별40단위 간격 4방향 격자 최단 경로로 기사에게 접근하고, 적 반경만큼 확장한 장애물·벽에 막히는 셀을 제외한다. 기사가 다른 셀로 이동하거나0.25초가 지날 때 경로를 갱신한다. 목표 셀이 막혀 있으면 가장 가까운 도달 가능 셀을 사용하고 동률은 위·오른쪽·아래·왼쪽 순서다. 장애물이 없는 방은 직선 접근, D에서는 경로를 따라 장애물을 우회한다. 적끼리 분리는 막힌 셀로 밀어내지 않고 벽에 막히면 분리 이동을 취소한다. blot은 제자리이며 D의(980,260)에서 장애물과 겹치지 않는다. 공격 물감은 장애물 통과를 허용하되 유효 반경만 제한한다; 적 몸·투사체 이동 충돌과 다른 규칙임을 명시한다.

## 5. 6구역·유한 배치·재진입

연결 그래프: `A 공방 ↔ B 연결 길 ↔ C 첫 공터 ↔ D 갈림 공터 ↔ E 정예 뜰 ↔ F 꽃집`. D는 선택 전투 가지를 방 내부 우측에 배치하여 구역을 더 늘리지 않는다. 외곽 출구는 동서 측 벽의 중앙 y280, 폭96. 입장 위치는 서쪽(90,280), 동쪽(1030,280); B 동쪽 입장은(1590,280). 출구 진입은 구역 내60×96 문 영역에 들어가 E키로 확정,0.2초 전환, 입력 취소·잔흔/투사체 제거, 다음 방은 새 press 요구. 전환 비용 없음.

## 7. 저장·재개·중복 방지

로컬 단일 프로필·스키마1. 저장 대상: 튜토리얼 플래그, 도구 보유, HP, 마을 지갑, 원정 장부, 정예/복원/종료 플래그, 구역 방문·적 스폰ID별 생존/HP·보상 지급 이력, 현재 구역·진입한 출구·마지막 안전 지점. 잉크·잔흔·누른 입력·피해 쿨다운·투사체는 저장하지 않는다.

원정ID는 신규 원정에만 생성하고, 보상키는 `프로필ID/스폰ID/최초처치`로 유지한다(이번 범위 리스폰 없음). 사건ID와 보상키는 다르다. 사망 상태+지급키+장부는 같은 저장 세대에 반영하고, 귀환은 지갑+장부0+마을상태를 같은 세대에, 구매는지갑차감+보유를 같은 세대에 저장한다. 임시파일 완성→기존 파일 교체의 원자 저장과 직전 유효 백업을 후보로 사용한다. 실패 시 성공 토스트·다음 출구/구매 완료 상태를 확정하지 않고 “저장 실패 · 다시 시도”를 제공한다.

모든 변경·저장은 단일 로컬 상태의 전체 스냅샷을 직렬 처리한다. 처치·구매·귀환·복원 같은 영구 사건은 직전 상태 복사본에 적용해 저장 성공 후 확정하고, 실패 시 직전 확정 상태로 복구한 뒤 재시도 안내한다. 처치 저장 실패는 해당 적을 직전 HP로 복구하고 전투를 일시정지해 보상 없는 사망 상태로 진행하지 않게 한다. 입력 사건을 별도 원격 큐나 복잡한 pending framework로 관리하지 않는다. 이 상태 세대는 백업파일 일치 확인용 저장 번호이며 부문별 분산 revision이 아니다.

자동 저장은 튜토리얼 단계, 처치 보상, 출구 전환, 복원, 귀환/패배, 구매, 정상 종료 때 한다. 일반 이동·피해HP는 진행상태를5초 간격으로 저장하되 즉시 보상 저장이 우선한다. 강제 종료 시 마지막 성공 저장 세대부터 재개하므로 이후 피해·이동은 되돌아갈 수 있음을 명시한다. 재개는 저장 구역의 진입 위치, HP는 저장값(사망이면A에서100), 전투 잉크100, 공격 없음. 잠긴E에서 재개하면 E 입장 위치에서 정예 저장HP·잠금 유지, 사망 정예는 재생성하지 않는다. 손실 데이터·손상 파일로 무조건 신규 프로필을 덮어쓰지 않고 백업복구 또는 새 게임 선택 안내한다.

튜토리얼 단계와 주기적 HP 저장은 한 시뮬레이션 처리 경계에서 전체 스냅샷을 복사하고 직렬로 기록한다. 정상 성공 저장은 현재 공격 hold·anchor·잔흔을 취소하거나 충전 지연을 재시작하지 않는다. 이 임시 런타임 입력은 디스크에만 포함하지 않는다. 저장 실패 시 앞선 실패 정책으로 pause/재시도하되 성공 후 물리 입력을 확인해 새 press를 요구한다. “저장 후 메뉴”는 입력 취소·일시정지 후 저장 성공 때만 메인 메뉴로 전환한다. 실패하면 현재 일시정지 화면에 남아 “저장 실패 · 다시 시도”를 표시하고 메뉴로 넘기지 않는다.

## 8. UI·자산·접근성 최소 규격

HUD: 좌상단 HP “체력 100/100”, 전투 잉크 막대 “전투 잉크”, 우상단 동전형 아이콘 “회수 잉크: 원정 n / 지갑 n”, 하단 도구 “1 붓 / 2 연필(미보유)”와 현재 목표 한 줄. recharge 상태는 “충전 대기”→“충전 중”→“가득 참”. 고갈은 “잉크가 비었어요 · 손을 떼어 충전”, 범위 밖은X 커서와 짧은 문구. 일시정지Esc: 계속/설정/저장 후 메뉴. 메뉴에는 새 게임/이어하기/설정/종료, 기존 목업 스타일 참고.

이어하기는 유효 프로필 또는 복구 가능한 백업이 있을 때만 활성화한다. 기존 프로필이 있는 새 게임은 “기존 여정이 삭제됩니다 · 새로 시작할까요?” 확인/취소가 필수이며 취소 시 기존 저장을 유지한다. 확인하면 새 프로필ID·초기 상태를 원자 저장에 성공한 뒤 A에서 시작한다; 실패하면 기존 프로필을 유지하고 오류 안내한다. 프로필이 없으면 새 게임은 확인창 없이 초기 저장 후 시작한다. 손상 저장에는 복구/새 게임 선택을 제공하고 새 게임도 기존 데이터 교체 확인을 거친다.

## 11. 검토 요청·남은 한계

master가 이 상세안의 일관성·첫10분 충분성을 검토해 2026.10.03 accepted로 판정했다. 문서 자체의 수치 계산·조건·배치·보상 총합을 대조했으나 실제 전투 균형은 미검증이다. 정예 피해를 패배 후 유지하는 관대한 규칙, 잔흔 수명, 연필 효율, 고정카메라가 주요 플레이 검토 대상이다. 최종 플랫폼·시점·확장 재화·패배손실·새도구·후속지역은 사용자 결정 또는 후속 기획으로 남긴다. 이 승인은 첫10분 프로토타입 구현 계획을 작성할 기준이 충분하다는 뜻이며 실제 구현·검증 완료나 최종 제품 수치 확정이 아니다. 이번 산출물은 상세 기획이다.

### master 수정 요청 4항 반영 기록

1. D 장애물·외곽의 기사/적/투사체 충돌, 돌진 충돌 종료와40단위 격자 경로 우회 정책을 추가했다. 인수 시 D 접근 적이 장애물에 갇히지 않고 투사체·돌진이 벽을 통과하지 않는지 확인한다.
2. D에서 정예 출구 확인/취소 후 전환, 모든 입장·재개 기사 무적0.75초와 적 활성0.75초 지연을 추가했다. 낮은 HP E 재개도 즉시 피해가 없어야 한다.
3. 새 게임 기존 프로필 교체 확인, 이어하기 조건, 저장 후 메뉴 실패 잔류, 튜토리얼 정상 저장의 공격 연속성을 추가했다. 실패·취소에서 기존 저장 유지 및 공격 중 정상 단계 저장이 hold를 끊지 않음을 확인한다.
4. 물리 커서와 world 유지점 표시를 분리하고 실제 마우스 이동 시 재anchor·두 끝점 유효 범위 조건과 경계 fallback을 명시했다. 추적 카메라 이동 중 실제 공격 위치와 커서 차이를 읽을 수 있고 유령 선이 없어야 한다.

회복 총4초와 나머지 초기값은 유지했다. 수정 제출 시에는 재검토 요청(submitted)으로 기록했으며, master가 실제 파일의 수정4항을 확인한 뒤 최종 accepted를 전달했다. 최초 제출→수정 요청→동일 파일 보완 제출→master 최종 승인 순서를 보존한다. 수정4항 단계에서는 동일 보고서만 변경했고, 최종 승인 이후 master 배정에 따라 game-direction v0.5에 승인 기준을 반영했다.
