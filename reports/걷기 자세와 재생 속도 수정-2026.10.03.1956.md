# 걷기 자세와 재생 속도 수정

Godot 4.7.2 / 2026-10-03.

기존 8프레임 시트의 다리 벌림/모음 반복은 실제 통과 자세가 부족했고, 프레임 개수 검사만으로 자연스러움을 증명할 수 없었다. 걷기 전용 8프레임 시트를 생성하여 무릎 굽힘과 발 통과 자세를 보강했다. 대기 시트는 유지했다. 걷기 16fps를 12fps로 조정하고 애니메이션별 시트 및 크기 값을 사용해 머리 크기와 발 기준점을 맞췄다.

검증: import와 기존 6개 테스트 모두 exit 0, 성공 marker 확인, stderr 비어 있음. 실제 게임 캡처 48장과 GIF 생성. 캡처는 2배 카메라/HUD 숨김 fixture이며 일반 플레이 설정은 유지. 자동 생성 자세의 미적 자연스러움과 정확한 다리 교대는 테스트가 보장하지 않으며 사용자 플레이 평가가 필요하다.

증거: docs/verification/player-walk-fix/manifest.json 및 movement-preview.gif.

Self-learning: 프레임 개수 통과를 미적 합격으로 승격하지 않는다는 교훈은 기록하되, 자연스러움에 대한 인간 평가가 아직 없으므로 새로운 검증 완료 스킬로 승격하지 않았다. 권한/설정/지침 변경 및 커밋 없음.
