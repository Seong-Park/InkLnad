# 기사 대기와 걷기 8프레임 확장

- Godot 4.7.2. 사용자 요청에 따라 각 4프레임을 실제 서로 다른 자세의 8프레임으로 확장.
- imagegen 스킬로 기존 기사 기준 투명 4×4 시트 생성: `godot/assets/characters/knight-motion-8.png`. 원본 4프레임 시트 보존.
- Godot animation 스킬 적용. 대기 8fps(1초 주기), 걷기 16fps(0.5초 주기). 기존 이동 속도 180과 동작 주기 유지.
- 16개 프레임 Atlas 영역 및 발 기준점 기록, 재생과 좌우 반전 시 정렬.
- MCP 프로젝트 identity 확인, 열린 파일 씬 없음 확인, 라이브 게임 중지 후 수정.
- headless import 및 gameplay/economy/save/journey/input-combat/player-motion 6개 테스트 전부 exit 0, 성공 marker 확인, stderr 비어 있음.
- 실제 게임 캡처 48장, 캡처 실행 exit 0 / INK_MOTION_CAPTURE_PASS / stderr 비어 있음. 2배 카메라와 HUD 숨김은 캡처 fixture에만 적용.
- 증거: `docs/verification/player-motion-8/manifest.json`, `frames/`, `movement-preview.gif`.
- 인트로와 게임 이동 규칙 유지. 자동 생성 포즈이며 인간 평가에 따른 추가 조정 가능.
- self-learning 검토: 기존 검증 절차를 재사용했고 새로운 실패/해결 사례가 없어 별도 스킬 변경 없음.
