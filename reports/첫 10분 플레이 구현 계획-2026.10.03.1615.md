# 첫 10분 플레이 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. 사용자 요청에 따른 매니저→워커→검토 순환과 기존 역할 문서를 함께 따른다.

**Goal:** 공방에서 직접 그리기를 배우고, 연결된 전투방을 지나 꽃집을 복원한 뒤 귀환·연필 구매·시험까지 완료하는 로컬 플레이를 만든다.

**Architecture:** Godot 노드 조합으로 구성한다. 순수 전투 규칙은 RefCounted, 이동과 적·방은 재사용 씬, 경제·저장은 하나의 로컬 상태 소유자로 둔다. UI와 그림은 승인된 상태와 공격 형상을 표시하며 원격 서버·DB·범용 이벤트버스를 추가하지 않는다.

**Tech Stack:** Godot 4.7.2, GDScript, Control/Node2D/CharacterBody2D/Area2D, 로컬 JSON 스냅샷, 외부 테스트 애드온 없는 SceneTree runner.

**Spec:** [첫 10분 플레이 상세 기획](첫%2010분%20플레이%20상세%20기획-2026.10.03.1611.md). master 승인 기록은 [충분성 검토](첫%2010분%20기획%20충분성%20검토-2026.10.03.1611.md). 최초 제출본에 대한 네 가지 수정이 반영되고 master가 accepted한 버전을 구현 기준으로 읽는다.

| QA | `godot/tests/integration/`, `docs/verification/first-journey/` | 첫10분 통합·실행 증거 |

중앙 `Main`이 Player·Area·전투규칙·경제서비스·UI를 조합하고 직접 신호를 연결한다. 별도 autoload나 서버는 필요 없다. gameplay는 전체 world 변환과 Camera2D를 단독 소유한다. 시각 자식은 발 원점 local(0,0)만 사용한다.

공통 표기는 GDScript 타입이다. Dictionary는 아래 키가 고정된 작은 데이터이며 외부 DTO 프레임워크를 뜻하지 않는다.

- `Pointer`: `{phase: StringName, screen: Vector2, ui_consumed: bool, physical_motion: bool}`; phase는 press/move/release/cancel.
- `Stamp`: `{id: int, tool_id: StringName, center: Vector2, radius: float, refreshed_at: float, expires_at: float}`. 게임 시간은 초, 도구 ID는 brush/pencil.
- `EnemyState`: `{spawn_id: StringName, enemy_id: StringName, hp: float, alive: bool}`. 상세 기획의 c01/d01/e01 등 안정적인 ID를 사용한다.
- `Result`: `{ok: bool, reason: StringName}`. 실패 이유는 ink_low/range/ui/locked/missing_tool/missing_funds/save_failed/corrupt_save 중 해당값 또는 성공 none.
