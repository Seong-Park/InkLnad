# 걷기 상체와 팔 동작 개선

2026-10-03 / Godot 4.7.2

사용자 지적: 걷기 중 대기와 같은 상체 고정. 기존 v2는 머리, 몸통, 붓 팔 고정에 가까웠으며 다리만 바뀌었다. imagegen으로 걷기 전용 v3 8프레임을 생성하여 앞쪽 체중 이동, 팔꿈치와 붓 각도 변화, 반대 팔 동작, 상체 높이와 옷자락 변화를 넣었다. 대기/인트로 유지.

정렬: 프레임별 머리 중심 추정 정렬은 움직임을 지워 버릴 수 있다. 걷기를 시트 셀의 고정 가로 300, 바닥 기준 420/842에 정렬해 그림에 포함된 상체 이동을 보존했다. 전신 스프라이트 회전은 적용하지 않았다.

MCP project identity 및 빈 열린 씬 확인 후 게임 중지, 파일 수정. import 및 6개 테스트 모두 exit 0 / marker 존재 / stderr 비어 있음. 실제 game capture 48장, INK_MOTION_CAPTURE_PASS / exit 0 / stderr 비어 있음. 증거: docs/verification/player-torso-fix/manifest.json, frames/, movement-preview.gif. 캡처 2배 카메라와 HUD 숨김은 테스트용. 기능 통과는 미적 자연스러움이나 정확한 생체역학을 보장하지 않음.

Self-learning 검토: 머리 자동 정렬이 상체 움직임을 상쇄한다는 관찰은 기록했지만 사용자 시각 평가가 아직 없으므로 검증 완료 스킬로 승격하지 않았다. 사용자 설정/권한/지침 변경과 커밋 없음.
